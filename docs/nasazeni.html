Nasazení na nový server

Krok za krokem od prázdného účtu po chat na adrese ai.skolagaudi.cz. Na server přijde pět částí: Vchod, Chat, Brána, Databáze a Terminál. Poskytovatelé (Anthropic, Google) zůstávají venku; připojíš se k nim jen klíči.

    Příkazy pocházejí ze skriptů v repu (scripts/bootstrap.sh, scripts/smoke.sh, scripts/backup.sh). Průvodce se ověří při prvním skutečném nasazení; co nebude sedět, oprav tady.
